Personal Project · 2026

findata — 금융 데이터 수집 라이브러리findata — Financial Data Toolkit

환율·주가지수·국토부 아파트 실거래가·부동산 매물을 하나의 파이썬 인터페이스로 모은 라이브러리. 공공 API의 요청 차단을 우회하고, 문서화되지 않은 엔드포인트는 웹앱 JS 번들을 리버싱해 규명했습니다. parquet 캐시와 회귀 테스트로 외부 API 변경에 대비했고, 데모는 집 서버에서 Tailscale Funnel로 직접 서빙합니다(응답 캐시·rate limit 적용). A Python library unifying FX rates, market indices, government apartment transaction records, and property listings. Worked around public-API request blocking and reverse-engineered undocumented endpoints from a web app's JS bundles. Hardened with a parquet cache and regression tests; the demo is self-hosted from a home server over Tailscale Funnel, with response caching and rate limiting.

Personal Project · 2026

asset-flow — 자산·현금흐름 트래커asset-flow — Asset & Cash-Flow Tracker

가계부의 기록 부담 없이 순자산과 향후 현금 잔고를 추적하는 도구. 영수증 단위 지출 대신 계정 스냅샷과 "t개월간 월 x원" 형태의 반복 현금흐름만 기록하는 모델로, 입력 비용을 최소화했습니다. 실제 잔고 변화와 등록된 흐름의 차이를 자동으로 대조해 미등록 지출을 추정하므로, 잔 지출을 적지 않아도 추정치가 현실과 어긋나지 않습니다. 보유 종목은 yfinance 시세로 자동 평가(외화는 환율 환산)하고, 차트는 의존성 없이 SVG로 직접 그렸습니다. A net-worth and cash-flow tracker that skips the bookkeeping burden of a ledger. Instead of itemising receipts it records only account snapshots and recurring flows of the form "x per month for t months", keeping data entry near zero. A reconciliation pass compares actual balance changes against registered flows to estimate unlogged spending, so the projection stays honest without itemising anything. Holdings are priced automatically via yfinance with FX conversion, and every chart is hand-rolled SVG with no dependencies.
