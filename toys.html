Personal Project · 2026

findata — 금융 데이터 수집 라이브러리findata — Financial Data Toolkit

환율·주가지수·국토부 아파트 실거래가·부동산 매물을 하나의 파이썬 인터페이스로 모은 라이브러리. 공공 API의 요청 차단을 우회하고, 문서화되지 않은 엔드포인트는 웹앱 JS 번들을 리버싱해 규명했습니다. parquet 캐시와 회귀 테스트로 외부 API 변경에 대비했고, 데모는 집 서버에서 Tailscale Funnel로 직접 서빙합니다(응답 캐시·rate limit 적용). A Python library unifying FX rates, market indices, government apartment transaction records, and property listings. Worked around public-API request blocking and reverse-engineered undocumented endpoints from a web app's JS bundles. Hardened with a parquet cache and regression tests; the demo is self-hosted from a home server over Tailscale Funnel, with response caching and rate limiting.
